# Landing page

`docs/index.html` is the standalone landing page for PyQuest.

## Publishing

Enable **GitHub Pages**: repo Settings → Pages → Source = `Deploy from a branch`, Branch = `main`, Folder = `/docs`. After ~30 seconds the page is live at `https://ahmedbosaad.github.io/PyQuest/`.

## Files

- `index.html`: the single-page landing site
- `banner.png`: hero image, referenced by `index.html`
