Built for first-time programmers.

Ten hand-written chapters, instant feedback, and a tutor that meets you where you are. Nothing about PyQuest tries to be a textbook.

i

10 chapters, hand-written

From "what is programming?" to lists. Each lesson is short, has a worked example, two hints, an auto-check, and a quiz.

ii

Sandboxed code playground

Syntax highlighting, line numbers, smart indent. Your code runs in a separate process with a 5-second timeout and dangerous imports blocked.

iii

Offline neural voice

Kokoro reads each lesson aloud. 28 voices, runs on CPU, downloads once (~340 MB). No subscriptions.

iv

Voice commands

Toggle the mic and say "run", "check answer", "next", "explain the error". Vosk runs fully offline.

v

Optional AI tutor

Connect a local LM Studio model. The tutor sees your code + last error and hints without giving away the solution. Three personas.

vi

XP · streaks · badges

Daily streaks with Duolingo-style freeze refills. Wax-seal-style mark badges. Editorial dark or light theme.

Set up in three steps.

Tested on Windows 11 with Python 3.11. Works on macOS and Linux too; see the README for platform notes.

required

Clone & install

You'll need Python 3.10 or newer. Anything from the last few years works.

git clone https://github.com/AhmedBoSaad/PyQuest.git
cd pyquest
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
pip install -e .
required

Launch PyQuest

The welcome wizard walks you through optional downloads on first run.

python run.py
# or, since the package installs a launcher:
pyquest
On first launch you'll be offered to download the voice (~340 MB) and the speech model (~50 MB). Both can be skipped and downloaded later from Settings.
optional

Wire up the AI tutor

The tutor uses a local LLM you run yourself via LM Studio. No API keys. No internet.

# 1. Install LM Studio and pull any chat model (Llama 3.2, Qwen 2.5, ...).
# 2. Open LM Studio → Local Server → Start Server.
# 3. In PyQuest → Settings → AI Tutor → click Refresh.
# 4. Pick the model from the dropdown.
PyQuest is fully functional without the tutor. It just adds proactive hints and the chat drawer.

Pick a tutor mood.

Three personalities ship out of the box. Personas live in a JSON file; add your own without touching code.

default

Friendly tutor

"That's not quite right. Let's look at line three together. You're really close."

no coddling

Strict instructor

"Wrong. You forgot a comma. Read your code line by line before you run it next time."

nsfw-light · escalates

Drill sergeant

"Oh for the love of... you forgot a goddamn comma. Look at line three. Are you trying to write Python or interpret modern art?"

Drill sergeant escalates as you accumulate mistakes inside a single lesson, and resets when you start a new one. The teaching rules never bend: it always points at the specific bug and never writes the full solution.
